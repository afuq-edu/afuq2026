# نجم الأسبوع

منصة تحدٍّ أسبوعي للطالبات بطابع جغرافي هادئ (بوصلة، كرة أرضية تدور، خطوط كنتورية) على أساس لمسات «مدار».

- **الواجهة الأولى** بمدخلين: «دخول الطالبات» و«دخول المعلمة».
- **الطالبة:** الاسم الرباعي (والصف) ← سؤال الأسبوع (اختيار من متعدد أو مقالي، مع صورة اختيارية) ← تقييم فوري وإجابة نموذجية وملاحظات المعلمة ← بطاقة شكر باسمها تُحفظ صورة PNG أو تُشارك.
- **المعلمة** (كلمة سر): متابعة حية للمنجزات بوقت التسليم، خريطة الإنجاز، بحث وتصفية، تقدير ورسالة خاصة لكل طالبة، قرعة نجم الأسبوع، تصدير Excel وطباعة؛ الأسئلة (إضافة، تعديل، فتح/إغلاق)؛ لوحة الشرف؛ الإعدادات (اسم المبادرة والمعلمة والمدرسة والشعار والصفوف وعدد الطالبات، رابط الطالبات ورمز QR).

## المزامنة: Google Firebase
- `firebase-config.js` يحمل مفاتيح المشروع (عامة). إن بقي `null` تعمل المنصة على الجهاز وحده.
- الطالبات يدخلن دخولًا مجهولًا (Anonymous) تلقائيًا؛ المعلمة حساب واحد `muallima@najm.ofuq.team` تختار كلمة سره أول مرة من المنصة.
- يلزم تفعيل **Email/Password** و**Anonymous** في Authentication، ونشر `firestore.rules`.
- القواعد: الإجابة النموذجية لا تُقرأ إلا بعد التسليم، تسليم واحد لكل جهاز في كل سؤال ولا تعديل بعده، ولا يُقبل التسليم إلا في السؤال المفتوح، وقائمة التسليمات للمعلمة وحدها.
- نسيان كلمة السر: احذفي المستخدم muallima@najm.ofuq.team من Authentication › Users ثم أنشئيها من جديد من المنصة.

المنصة غير مقفلة بـ lock.mjs لأن مدخل الطالبات يجب أن يبقى مفتوحًا؛ لوحة المعلمة محمية بتسجيل الدخول وقواعد Firestore.
