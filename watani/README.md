# هذا وطني · المسابقة المنهجية

منصة المسابقة المنهجية «هذا وطني» للصف الحادي عشر (الفصل الدراسي الأول، الدرسان الأول والثاني) لمعلمات الدراسات الاجتماعية بمدرسة نسيبة بنت كعب (١١–١٢)، نوفمبر ٢٠٢٦م، للشعب من ١١/١ إلى ١١/١٢.

## الأقسام

- **صفحة الطالبات** (`#/`): تكتب الطالبة اسمها وتختار شعبتها، فتظهر لها الجولات المفتوحة لشعبتها، تجيب بمؤقت لكل سؤال، وترى نتيجتها ومراجعة إجاباتها بعد التسليم.
- **قسم المعلمات** (`#/t`، بكلمة سر):
  - الجولات: أربعة أنواع (تصفيات الشعب، المسابقة الفردية، تحدي السرعة، جولة تدريبية)، واختيار الدروس والأنواع وعدد الأسئلة لكل مستوى معرفي أو اختيار الأسئلة يدويًا، ثم فتح الجولة وإغلاقها.
  - أسماء الطالبات ونتائجهن لحظيًا، ومتوسط الشعب، ونسبة الإجابة الصحيحة لكل سؤال، وتصحيح الإجابات القصيرة، وتصدير Excel.
  - النتائج والإحصاءات العامة: ترتيب الشعب، والإتقان حسب المستوى ونوع السؤال، والأسئلة الأصعب.
  - التصفيات: قرعة بين ١٢ شعبة بثلاثة أنظمة، وتأهّل الفائزات حتى النهائي.
  - ساحة العرض: مواجهة حية على شاشة الصف بالدور أو للأسرع، مع الاستحواذ والتراجع.
  - لوحة الشرف والمعرض، والشهادات (A4)، وبنك الأسئلة القابل للتعديل والإضافة، والإعدادات والنسخة الاحتياطية.

## التقنية

- ملفات ثابتة (PWA) تعمل على GitHub Pages، مع زر تثبيت وتعليمات Safari.
- المزامنة عبر Firebase (مشروع `najm-alusbu-8613`، مجموعات `watani_*`). قواعد الحماية في `firestore.rules` وتُدمج مع قواعد «نجم الأسبوع».
- لا تُنشر أسماء الطالبات للعموم: لوحة الشرف المنشورة تعرض أسماء الشعب فقط، والإجابات النموذجية لا تصل للطالبة إلا بعد تسليمها.
- `bank.js` بنك أسئلة الدرسين (١٠٩ أسئلة) من دليل المعلم وكتاب الطالب.
